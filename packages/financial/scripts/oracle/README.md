# Study oracle

Independent cross-validation of `@pond-ts/financial` studies against a
**pandas** reference (the open-source numerical reference — think MATLAB, but
free and what quant practitioners actually use). `generate.py` computes the
expected indicator values with pandas and writes the golden fixture
[`../../test/fixtures/study-oracle.json`](../../test/fixtures/study-oracle.json);
[`../../test/study-oracle.test.ts`](../../test/study-oracle.test.ts) runs our
TypeScript studies over the same input and asserts bar-for-bar agreement.

**CI needs no Python** — the JSON is the committed oracle. You only run the
generator when a study's definition changes (and the fixture diff should be
reviewed as carefully as the code).

> **Adding a study?** An oracle case here is a **required** step, not an
> afterthought — see the full checklist in
> [`../../src/studies/README.md`](../../src/studies/README.md).

## Regenerate

```sh
python3 -m venv .venv
.venv/bin/pip install pandas
.venv/bin/python packages/financial/scripts/oracle/generate.py
```

Then run the suite (`npm test --workspace=@pond-ts/financial`) to confirm the
TypeScript still matches, and commit the updated JSON.

## Conventions (why the numbers line up)

An oracle only helps if its conventions match ours — the defaults will not:

| study         | pandas                                                                                                        | note                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ------------- | ------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| SMA           | `close.rolling(n).mean()`                                                                                     | —                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| EMA           | `close.ewm(span=n, adjust=False).mean()`                                                                      | `adjust=False` (recursive); **not** the default                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| movingAverage | the ten-type K2 menu (`sma`/`ema`/`wma`/`smma`/`dema`/`tema`/`trima`/`hull`/`kama`/`zlema`), two periods each | **cross-checked against TA-Lib `MA(matype=…)`** for the seven it ships. `sma` 0 / `wma` 2 / `trima` 5 / `kama` 6 agree **exactly** (mask + values). `ema` 1 / `dema` 3 / `tema` 4 keep **pond's first-sample EMA seed** rather than TA-Lib's SMA seed (the `macd` precedent — otherwise the engine would disagree with `ema()` inside the package): identical null masks, values asserted as a decaying **tail bound**. `smma` (Wilder), `hull` and `zlema` have no TA-Lib function — pandas replications with the analytic first-valid bar asserted. The generator also asserts the ten types are **pairwise separated** on the fixture, so a dispatch that ignored `type` could not pass. |
| Bollinger     | `middle ± k · close.rolling(n).std(ddof=0)`                                                                   | **population** stdev (TA-Lib's), not pandas' ddof=1                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| RSI           | Wilder: seed = mean of first `n` diffs, then `(prev·(n−1)+x)/n`                                               | **cross-checked against TA-Lib** — the generator asserts the warm-up mask _and_ the values, and fails rather than writing a drifted fixture. A first-sample-seeded EMA of the same `α` is a different indicator (7+ RSI points out).                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ROC           | `close.pct_change(n) * 100`                                                                                   | **is `percentChange`** — cross-checked against TA-Lib `ROC` (exact, identical warm-up). No separate `roc` study.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| momentum      | `close.diff(n)`                                                                                               | **cross-checked against TA-Lib `MOM`** (exact, identical warm-up).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| HV            | `np.log(close).diff().rolling(n).std(ddof=0) * sqrt(annualize)`                                               | **population** σ of **log** returns, a decimal; `annualize` is a study option (default 252). TA-Lib has no HV, so pandas is the only oracle; the generator asserts the first valid bar is `n`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| Stochastic    | `fast %K = 100·(c − LL)/(HH − LL)`; `%K = fast.rolling(slowing).mean()`; `%D = %K.rolling(d).mean()`          | **cross-checked against TA-Lib `STOCH`** (and `STOCHF` when `slowing = 1`): `%D` mask + values; `%K` values on every bar TA-Lib emits, and its mask from TA-Lib's first bar on — ours starts exactly `dPeriod − 1` bars earlier (TA-Lib masks `%K` to `%D`'s start; we emit it where defined, as `macd` does).                                                                                                                                                                                                                                                                                                                                                                              |
| Williams %R   | `−100·(HH − c)/(HH − LL)`                                                                                     | **cross-checked against TA-Lib `WILLR`** — mask and values.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| Donchian      | `high.rolling(n).max()`, `low.rolling(n).min()`, midpoint                                                     | pandas only — TA-Lib has no Donchian.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| OBV           | `cumsum(sign(close.diff()) · volume)`, `OBV[0] = volume[0]`                                                   | **cross-checked against TA-Lib** (mask and values). The `volume[0]` seed is TA-Lib's convention; some implementations seed at 0, which only offsets the line. No period, no warm-up.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| VWAP          | `(tp·v).rolling(n).sum() / v.rolling(n).sum()`, `tp = (h+l+c)/3`                                              | **pandas replication only** — TA-Lib has no VWAP. Rolling, not anchored (a design decision documented on the study). The generator asserts the fixture's volume separates it from the plain mean of `tp` by > 0.25.                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| Keltner       | `MA(tp, n) ± mult · ATR(atr_n)`, `tp = (h+l+c)/3`                                                             | **pandas replication** reusing the TA-Lib-checked ATR — the **modern** variant (Keltner via Raschke; ChartIQ's default): EMA(20) of typical price ± 2·ATR(10). The 1960 original (SMA of typical price ± 1× the SMA of the **plain** range) is a documented delta, not an option. Per-column warm-up asserted: centre at the MA's own first bar, bands at `max(centre, ATR)`.                                                                                                                                                                                                                                                                                                               |
| ATR Bands     | `close ± mult · ATR(n)`                                                                                       | **pandas replication** on the same ATR; two columns (no middle — it is the field). `upper − close == mult · atr` asserted (to 7.1e-15 by subtraction; the bit-exact form is pinned TypeScript-side against the shipped `atr` study).                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| QStick        | `MA(close − open, n)`                                                                                         | **pandas replication** — TA-Lib has no QSTICK. Needs the fixture's new `opens` column (the previous close pulled inside the bar; 30 of 80 bodies negative, all 80 distinct — asserted, so a dropped sign cannot pass).                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| TRIX          | `100·(T[i]/T[i−1] − 1)`, `T = EMA(EMA(EMA(x, n)))`; signal `EMA(trix, sig)`                                   | **cross-checked against TA-Lib `TRIX`** by the EMA-family pattern: the **formula** is asserted **bit-exact on TA-Lib's own SMA seed** (2.2e-14 — this is what catches a log-vs-percent ROC, a dropped stage or a `tema` substituted for the EMA chain), pond's first-sample seed bounded at the tail (8.75% → 0.85% of scale at `n = 15`; the wrong rates sit at 8.5% / 9.8%). The signal has no vendor reference — TA-Lib returns the line alone.                                                                                                                                                                                                                                          |
| Coppock       | `WMA(pct_change(long)·100 + pct_change(short)·100, wma)`                                                      | **pandas replication** — no TA-Lib Coppock. Built on the same `pct_change` and linear-weight helpers the TA-Lib-verified `ROC` and `MA(matype=2)` cases use, so the case pins the **assembly** and its composed warm-up (`max(long, short) + wma − 1`). Coppock's periods are **monthly**; the study is bar-count.                                                                                                                                                                                                                                                                                                                                                                          |
| Price Osc.    | `MA(fast) − MA(slow)` / `100·(MA(fast) − MA(slow))/MA(slow)`                                                  | **cross-checked against TA-Lib `APO` / `PPO`(matype)** — the generator first rebuilds both from `talib.MA` and confirms that identity (`8.9e-16`). `{sma, absolute}` matches outright (`7.1e-14`, identical mask); `{ema, percent}` keeps **pond's EMA seed** (the `macd` precedent), so the formula is proven on TA-Lib's SMA seed and the transient bounded at the tail (6.61% → 0.41% of scale; a wrong rate is 5.1%+). A separation assert stops a study that ignored `mode` from passing both cases.                                                                                                                                                                                   |
| Disparity     | `100·(close − MA)/MA`                                                                                         | **pandas replication** — no TA-Lib function. First valid bar asserted; separated from the divide-by-**price** version (> 0.01) so the denominator is pinned.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| DPO           | `close − MA.shift(⌊n/2⌋+1)`                                                                                   | **pandas replication** — no TA-Lib function. The **non-centered** alignment (TradingView's default), not StockCharts' centered one. First valid at `n−1+shift`; separated from the **undisplaced** `close − MA` (> 0.5), which is the bug this study can have.                                                                                                                                                                                                                                                                                                                                                                                                                              |
| Elder Ray     | `high − EMA(close, n)`, `low − EMA(close, n)`                                                                 | **pandas replication** on pond's first-sample EMA seed — no TA-Lib function. First valid at `n−1` on both legs; the legs are asserted to be > 0.5 apart, and `bull` separated from a close-based version, so a study reading the wrong column fails.                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| Awesome Osc.  | `med.rolling(5).mean() − med.rolling(34).mean()`, `med = (h+l)/2`                                             | **pandas replication** — no TA-Lib function. pandas' `rolling` needs `n` non-NaN observations, which is our derived-array rule (`rollingMeanValues`). First valid at `slow−1`; separated from a **close**-based version so the median price is pinned.                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| A/D line      | `cumsum(CLV·volume)`, `CLV = ((c−l)−(h−c))/(h−l)`                                                             | **cross-checked against TA-Lib `AD`** (mask and values, delta 0). No period, no warm-up. A **flat bar** (`h == l`) is the documented delta: TA-Lib folds it in as a zero contribution, pond has no close location for it and the running sum stops. The fixture always has a range, so that case is unit-tested TypeScript-side.                                                                                                                                                                                                                                                                                                                                                            |
| Chaikin Osc.  | `EMA(AD, fast) − EMA(AD, slow)`                                                                               | **cross-checked against TA-Lib `ADOSC`** — **exactly**, and it is the only EMA-family case here with no seed delta: TA-Lib's `ADOSC` seeds both EMAs on the **first** A/D value, which is pond's own convention. The generator also asserts the SMA-seeded reconstruction is far from `ADOSC`, so the case pins the seed rather than being blind to it.                                                                                                                                                                                                                                                                                                                                     |
| PVT           | `cumsum(close.pct_change()·volume)`                                                                           | **pandas replication** — no TA-Lib PVT. The **fractional** change, not the percent one. `PVT[0]` is null (no previous close, and no vendor convention to seed from); first valid at 1, separated from the absolute-change version.                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| CMF           | `(CLV·v).rolling(n).sum() / v.rolling(n).sum()`                                                               | **pandas replication** — no TA-Lib CMF; the same weighted-mean shape VWAP uses. First valid at `n−1`, bounded by ±1, and separated from the **unweighted** mean of CLV (0.047 at n=20, 0.133 at n=5) so a dropped weighting cannot pass.                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| MFI           | `100·posFlow/(posFlow+negFlow)`, flow = `tp·v`, direction from `tp`                                           | **cross-checked against TA-Lib `MFI`** (2.8e-14, identical masks). Unchanged `tp` counts for neither side — TA-Lib's rule. Warm-up is `n` rows, not `n−1`. TA-Lib reports **0** for a window whose total flow is zero, or merely **below 1.0**; pond reports null for a zero total (the RSI flat-window rule) and has no magnitude threshold. Neither case arises on this fixture.                                                                                                                                                                                                                                                                                                          |
| Force Index   | `EMA(close.diff()·volume, n)` on pond's EMA seed                                                              | **pandas replication** — no TA-Lib function. First valid at `n`, not `n−1`: the raw force has no value on bar 0 and the EMA array door waits for `n` finite **values**. Separated from the volume-less version.                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| EOM           | `MA(mid.diff()·(h−l)·scale/volume, n)`                                                                        | **pandas replication** — no TA-Lib function. `scale` is StockCharts'/ChartIQ's 100,000,000 and is a pure linear multiplier. First valid at `n`; separated from the version that drops `(h−l)`, which is the half of the definition making EOM **quadratic** in price.                                                                                                                                                                                                                                                                                                                                                                                                                       |
| Volume Osc.   | `100·(MA(v,fast) − MA(v,slow))/MA(v,slow)`                                                                    | **pandas replication** — no TA-Lib function. The study delegates to `priceOscillator`'s percent mode, so what these cases pin is what that cannot: the **volume** column and the 5/10/sma defaults. Separated from the close-based version.                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| CMO           | `100·(Σup − Σdown)/(Σup + Σdown)` over `n`, plain sums                                                        | **pandas replication** — Chande's unsmoothed definition. TA-Lib's `CMO` is asserted to be exactly `2·RSI − 100` (a rename of a shipped study), and the delta from it is measured. Flat window → `null`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| Ultimate Osc. | `100·(4·A7 + 2·A14 + A28)/7`, `A = ΣBP/ΣTR`, `BP = c − min(l, prevC)`                                         | **cross-checked against TA-Lib `ULTOSC`** (7.1e-15, identical masks); `TR` asserted `== talib.TRANGE`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| CCI           | `(tp − SMA(tp,n)) / (0.015 · MAD(tp,n))`                                                                      | **cross-checked against TA-Lib `CCI`** (≤1.5e-11).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| IMI           | `100·Σ(c−o)⁺/(Σ(c−o)⁺ + Σ(o−c)⁺)` over `n`, plain sums                                                        | **pandas replication** — no TA-Lib function. Separated from the close-to-close form; the fixture's opens sit near the previous close, so the short case is period 8.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| RVI           | `Σ swma(c−o) / Σ swma(h−l)` over `n`, `swma = (1,2,2,1)/6`; signal = `swma(rvi)`                              | **pandas replication** (TradingView's definition) — no TA-Lib function. Per-column first valid at `n+2` / `n+5`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| PSY           | `100·count(c > prevC)/n`                                                                                      | **pandas replication** — no TA-Lib function. An unchanged close is not an up-close.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |

The EMA head is masked to the first `n-1` rows to match our length-preserving
`minSamples: n` warm-up. The input series is deliberately never flat, so the
`σ = 0 → undefined` band case (separately unit-tested in `studies.test.ts`)
doesn't arise here.

## Phase 2 (named indicators)

**RSI has landed** and does exactly this — see the table above. The remaining
MACD / ATR / stochastics add **TA-Lib** (`pip install TA-Lib`,
needs the C library — `brew install ta-lib`) alongside pandas, as the
industry-standard cross-check. Because those indicators have multiple published
definitions (Wilder smoothing, etc.), the oracle documents any delta from
TA-Lib rather than forcing bar-for-bar vendor parity (a non-goal — see
`docs/notes/financial-indicators-assessment-2026-07.md` §2).
